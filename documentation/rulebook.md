# Chronicles of the Fall Rulebook

The canonical prototype rules are maintained in [`../game_rules.md`](../game_rules.md).

That document defines the Anonymous Council Engine v0.2 and supersedes the former
Administration, Event Queue, Pitch, Exhaustion, mana-allocation, and Decay rules.

The implemented Era sequence is:

1. Ministry Assignment
2. Suspicion
3. Production
4. Queued Project Resolution
5. Plotting
6. Anonymous Reveal
7. Stalled Project Vote
8. Crisis
9. Storage
10. Scheme, Draw, and Cleanup

The Empire collapses immediately when any configured Pillar reaches zero.
